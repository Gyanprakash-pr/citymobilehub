# 🛒 OnlineBazar REST API Documentation

Welcome to the OnlineBazar API. This document provides all the necessary information to integrate the backend with Mobile Apps (Android/iOS) or Third-party services.

## 🚀 Base URL
The base URL for all API endpoints is:
`http://127.0.0.1:8000/api/`

---

## 🔐 Authentication
This API uses **Token-based Authentication**. All protected routes require a valid token in the request header.

### 1. Obtain Auth Token
To get a token, send a POST request with valid credentials.
- **Endpoint:** `/get-token/`
- **Method:** `POST`
- **Payload:**
```json
{
    "username": "your_username",
    "password": "your_password"
}
```
- **Success Response:**
```json
{
    "token": "9944b09199c62bcf445703e71db93cc95b4e9f3b"
}
```

### 2. Using the Token
Once you have the token, include it in the `Authorization` header for all subsequent requests:
`Authorization: Token 9944b09199c62bcf445703e71db93cc95b4e9f3b`

## 📦 API Endpoints

### 1. Products List
Get a list of all products available in the store.
- **Endpoint:** `/products/`
- **Method:** `GET`
- **Features:** Supports Searching, Filtering, and Ordering.
- **Filters:** `maincategory`, `subcategory`, `brand`, `seller`
- **Search Fields:** `name`, `description`

### 2. Main Categories
Get all main categories.
- **Endpoint:** `/maincategories/`
- **Method:** `GET`

### 3. Sub Categories
Get all sub-categories.
- **Endpoint:** `/subcategories/`
- **Method:** `GET`

### 4. Brands
Get list of brands.
- **Endpoint:** `/brands/`
- **Method:** `GET`

## 📝 Example Request (JavaScript/Fetch)
```javascript
fetch('http://127.0.0.1:8000/api/products/', {
    method: 'GET',
    headers: {
        'Authorization': 'Token YOUR_TOKEN_HERE',
        'Content-Type': 'application/json'
    }
})
.then(response => response.json())
.then(data => console.log(data));
```

## ⚠️ Error Codes
- `401 Unauthorized`: Token is missing or invalid.
- `403 Forbidden`: You don't have permission to perform this action.
- `404 Not Found`: The requested resource does not exist.
- `400 Bad Request`: Invalid data sent in POST/PUT request.
